# 🚗 CarPlay-Style Automotive UI (SwiftUI)

A CarPlay-inspired automotive dashboard built entirely with **SwiftUI**,
running on **Swift Playgrounds for iPad** — no Mac, no Xcode required.

## ✨ Features
- CarPlay-style layout
- Google Maps (real, via WebView)
- YouTube (real)
- Google Chrome-style browser
- Music player UI
- Phone call UI
- Driving mode overlay
- Smooth SwiftUI animations

## 🛠 Tech Stack
- SwiftUI
- WebKit
- Swift Playgrounds (iPad)

## 📱 Why this project?
This project explores how far SwiftUI can go **even with platform limitations**,
using creative solutions to integrate real-world services without native SDKs.

## 🚀 How to run
1. Open Swift Playgrounds on iPad
2. Create a new App project
3. Replace `IntroView.swift` with the file from this repo
4. Run 🚀

## ⚠️ Disclaimer
This is a **concept/demo project**.
Video playback while driving is shown for demonstration purposes only.
